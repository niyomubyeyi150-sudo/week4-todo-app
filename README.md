# Imboni — Community Action Planner 🌱

## 1. Project Overview

Imboni is a themed To-Do List web application designed to help people plan and manage community activities. Users can organize activities such as neighborhood cleanups, tree planting, tutoring, volunteering, and supporting local families.

The application provides a simple, responsive interface that helps users manage their activities, set priorities, track progress, and stay organized.

## 2. Technologies Used

- **HTML5** — Structures the application.
- **Tailwind CSS v4** — Styles the interface and creates responsive layouts.
- **Vanilla JavaScript** — Handles the application's interactive features.
- **Vite** — Runs the development server and builds the application.
- **LocalStorage** — Stores activities in the browser between sessions.
- **Git and GitHub** — Manage and store the source code.

## 3. Features

### Required Features

1. **Add Activities:** Create new community activities.
2. **Input Validation:** Prevent empty or invalid activity names.
3. **Complete Activities:** Mark activities as completed.
4. **Delete Activities:** Remove activities with a confirmation prompt.
5. **Edit Activities:** Update activity names directly in the activity list.
6. **Filter Activities:** View all, active, or completed activities.
7. **Activity Counter:** Display the number of activities remaining.
8. **Clear Completed:** Remove completed activities.
9. **LocalStorage Persistence:** Save activities in the browser so they remain available after refreshing the page.
10. **Empty State:** Display a helpful message when there are no activities to show.

### Additional Features

- **Activity Categories:** Organize activities into Environment, Education, Health, Community Support, and Other.
- **Priority Levels:** Assign High, Medium, or Low priority to activities.
- **Due Dates:** Set optional deadlines for activities.
- **Progress Tracking:** Display completed activities and a visual progress bar.
- **Category Filtering:** Filter activities by category.
- **Responsive Design:** Support different screen sizes.

## 4. Getting Started

### Prerequisites

Install Node.js and npm before running the project.

### Installation

**Step 1: Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 2: Open the project folder**

```bash
cd imboni-community-planner
```

**Step 3: Install dependencies**

```bash
npm install
```

**Step 4: Start the development server**

```bash
npm run dev
```

**Step 5: Open the application**

Visit the local URL displayed in your terminal, usually:

`http://localhost:5173`

## 5. How to Use the Application

1. Open the Imboni application.
2. Enter a community activity name.
3. Choose a category and priority.
4. Set a due date if needed.
5. Click **Add community activity**.
6. Mark activities as completed when finished.
7. Edit or delete activities when necessary.
8. Use the filters to organize your activities.
9. Monitor your progress using the progress summary.
10. Refresh the page to check whether activities are saved.
